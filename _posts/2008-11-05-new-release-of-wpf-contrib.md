I've released a new version of [WPF Contrib](https://github.com/aelij/WPFContrib) (October 2008, although it's released in November. I changed the release name a few times, so I decided to leave it like that. I'm only late by a few days...

<!--more-->

It contains quite a few fixes and new features. Read about it in the project wiki. Note there are some breaking changes. Although, many of the new features in TaskDialog were motivated by user requests. Many of the new controls and classes already appeared in articles in this blog.

As always, I would like to hear from you if you have suggestions and bugs.
